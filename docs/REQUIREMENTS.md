# Requirements and documentation map

## Scope and sources

This index records confirmed constraints of `rust-musl-libc-compat-test`, the single binary crate producing `musl-compat-test`. It is a focused Linux static-musl runtime probe, not a library API, comprehensive libc certification, or evidence that arbitrary applications work. Requirement IDs use the stable `MUSL-REQ` prefix; F6 remains the existing independent-review identifier.

Sources are [AGENTS.md](../AGENTS.md), the maintained guides mapped below, [Cargo.toml](../Cargo.toml), [.cargo/config.toml](../.cargo/config.toml), source, and [static musl CI](../.github/workflows/musl.yml). Inspection for this audit was on 2026-11-01 against baseline [`9aaee3acfef0e9f3a50dcf4d91f8771f276b15cd`](https://github.com/rustcommons/rust-musl-libc-compat-test/commit/9aaee3acfef0e9f3a50dcf4d91f8771f276b15cd). Source inspection establishes wiring and limitations, not successful execution on every host.

Historical native x86-64 Linux evidence: [CI run 41264143523](https://github.com/rustcommons/rust-musl-libc-compat-test/actions/runs/41264143523), 2026-11-01, revision `9aaee3acfef0e9f3a50dcf4d91f8771f276b15cd`, succeeded with 10 unit tests, 15 runtime probes, 12 concurrent runs, static ELF checks and stdout regressions. These are outcomes for that hosted environment. Earlier [CI run 41238463704](https://github.com/rustcommons/rust-musl-libc-compat-test/actions/runs/41238463704), 2026-10-31, revision `5ef07a1ac968bd7b25728dd3862eec2b559e11cc`, is the six-unit-test evidence retained in the roadmap. Neither run qualifies old hosts or all security policies. The documentation audit did not rerun Rust builds or runtime tests.

The repository is not published on crates.io; `0.1.0` in the manifest is not a publication record. No GitHub releases or tags were present at inspection. There is no published package/API documentation correction requiring a release from this audit.
